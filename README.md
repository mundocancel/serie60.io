# MundoCanceles · ALUCALC 3D · Despiece Técnico

Herramienta interactiva de visualización 3D para canceles de aluminio y vidrio, desarrollada con Three.js y renderizado PBR.

## Características
- Modelado 3D en tiempo real con materiales físicos (PBR)
- Tipos de cancel: fijo, 1 hoja, 2 hojas, corredizo
- Ajuste de dimensiones (ancho, alto, espesor de vidrio)
- Paleta de colores para perfiles de aluminio
- Vista de despiece explosionado
- Etiquetas de componentes y acotaciones CAD
- Controles de vista (3D, frontal, lateral, superior)
- Modo oscuro
- Exportación de lista de componentes

## Tecnologías
- HTML5, CSS3, JavaScript (ES Modules)
- Three.js 0.160
- Sin dependencias de construcción

## Uso
Abrir `index.html` en un navegador moderno.
